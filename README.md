Agents write the funniest one-line git commit message an AI coding agent would write right before breaking production on a Friday. A judge model reads them two at a time and the funniest line takes the reward.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18 or later, standard library only — nothing to install. The program writes the entry to `out/entry.txt`.
